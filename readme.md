# 🎮 Tic Tac Toe Game

A fun and interactive **Tic Tac Toe game** built using HTML, CSS, and JavaScript.  
Players can choose their characters, enter their names, and battle against each other in a stylish animated interface.

## ✨ Features

- 🎮 Two-player Tic Tac Toe gameplay
- 👤 Custom player names
- 🖼️ Character selection for both players
- ⚔️ Different characters for each player
- 🎨 Animated and interactive UI
- 🎵 Background/game animations
- 🏆 Winner detection
- 🎉 Winning animation
- 💥 Game-over detection
- 📱 Responsive design
- 💾 Uses Session Storage to transfer player data between screens

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Session Storage
- CSS Animations

## 🎯 How to Play

1. Enter Player 1 and Player 2 names.
2. Choose a different character for each player.
3. Click **Submit** to start the game.
4. Player 1 plays with **O**.
5. Player 2 plays with **X**.
6. Get three of your symbols in a row to win.
7. Enjoy the winning animation! 🎉

## 🎮 Game Rules

The objective is to get three matching symbols in:

- Horizontal row
- Vertical column
- Diagonal

The first player to complete one of these combinations wins the game.
